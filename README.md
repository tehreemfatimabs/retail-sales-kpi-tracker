# Retail Sales KPI Tracker — Excel

## Project Overview
An Excel-based dashboard that summarizes retail sales performance using key performance indicators (KPIs).

## KPIs
- **Total Revenue:** Total sales revenue.
- **Units Sold:** Total quantity sold.
- **Average Order Value:** Revenue divided by the number of unique orders.
- **Top Product by Revenue:** Product generating the highest total revenue.

## Tools Used
- Microsoft Excel
- Excel Tables and formulas
- Linked KPI cards
- Dashboard formatting and design

## Key Learning
The main thing I learned was how to connect formula cells to KPI cards to make them dynamic. When new records are added to the Excel Table and formulas recalculate, the linked cards can display updated results automatically.
